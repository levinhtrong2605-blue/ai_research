Toán học đi vào mô hình dự đoán

Dùng hàm số tuyến tính quen thuộc để hiểu 4 khái niệm: dữ liệu, tham số, dự đoán và loss. Điều quan trọng là biết thế nào là một thí nghiệm công bằng.

3. Kiến thức cốt lõi

1. Mô hình tuyến tính

Mô hình y_hat = wx+b nhận x và dự đoán y. Hai tham số w,b quyết định đường thẳng; mô hình chưa “học” nếu bạn chỉ tự chọn w,b.

2. Sai số bình phương trung bình

MSE = (1/n) Σ(y_i - y_hat_i)^2. Bình phương làm sai số lớn bị phạt nhiều hơn. Đây là hàm mất mát (loss) ta muốn giảm.

3. Tách dữ liệu

Nếu chỉ đo lỗi trên các điểm đã dùng để chọn mô hình, ta có thể đánh giá quá lạc quan. Test set được giữ riêng để kiểm tra khả năng khái quát.

4. Bài học về toán

Giải tích giúp tìm cực tiểu của loss, đại số tuyến tính giúp biểu diễn phép tính trên nhiều đặc trưng, xác suất giúp mô tả bất định và đánh giá thống kê.

4. Bài tập và câu hỏi tự kiểm tra

  1. Tính MSE với x=[1,2,3,4], y=[3,5,7,9], w=1,b=1.
  2. Đổi w=2,b=1: điều gì xảy ra?
  3. Nếu có thêm dữ liệu (x=5,y=20), mô hình cũ còn tốt không? Vì sao?
Xem gợi ý định hướng

w=2,b=1 cho MSE=0 trên 4 điểm ban đầu, nhưng không bảo đảm dự đoán chính xác mọi dữ liệu mới.

5. Ví dụ Python để tự chạy

Mở Google Colab, tạo notebook mới và dán mã dưới đây. Mã tương ứng có trong thư mục examples/.

"""Ngày 3: Thử tham số tuyến tính bằng tay; chưa tự huấn luyện."""
x = [1, 2, 3, 4]
y = [3, 5, 7, 9]

def predict(x_values, w, b):
    return [w * item + b for item in x_values]

def mse(true_values, predictions):
    return sum((a - b) ** 2 for a, b in zip(true_values, predictions)) / len(true_values)

for w, b in [(1, 1), (2, 1), (2, 0)]:
    yp = predict(x, w, b)
    print(f'w={w}, b={b}, predictions={yp}, MSE={mse(y, yp):.2f}')
