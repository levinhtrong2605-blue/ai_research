3. Kiến thức cốt lõi

1. C++ và Python: cùng tư duy

C++ dùng dấu ngoặc nhọn và kiểu tường minh; Python dùng thụt lề để biểu thị khối lệnh. Cả hai đều có biến, vòng lặp, hàm, điều kiện.

2. List như mảng động đơn giản

scores = [3,5,7] là danh sách. scores[0] trả 3. len(scores) trả số phần tử. Duyệt for s in scores giống lặp qua phần tử.

3. Hàm và kết quả

def mean(values): return sum(values)/len(values) định nghĩa hàm trung bình. Chưa cần class hay thư viện phức tạp.

4. Đọc lỗi là kỹ năng nghiên cứu

Nếu gặp NameError, kiểm tra tên biến. Nếu gặp IndentationError, xem thụt lề. Ghi lỗi và cách khắc phục vào notebook.

4. Bài tập và câu hỏi tự kiểm tra

  1. Tính trung bình của [6, 8, 9, 7] bằng Python.
  2. Viết hàm count_pass(scores, threshold) đếm điểm từ ngưỡng trở lên.
  3. Tạo dữ liệu mới và ghi kết quả trước/sau khi thay ngưỡng.
Xem gợi ý định hướng

Với [6,8,9,7], trung bình là 7.5. Có thể dùng sum(scores)/len(scores).

5. Ví dụ Python để tự chạy

Mở Google Colab, tạo notebook mới và dán mã dưới đây. Mã tương ứng có trong thư mục examples/.

"""Ngày 2: Các khái niệm Python cần cho nghiên cứu AI."""
scores = [6, 8, 9, 7]

def average(values):
    return sum(values) / len(values)

def count_pass(values, threshold=7):
    count = 0
    for score in values:
        if score >= threshold:
            count += 1
    return count

print('Điểm:', scores)
print('Trung bình:', average(scores))
for threshold in (6, 7, 8):
    print('Đạt từ', threshold, ':', count_pass(scores, threshold))
