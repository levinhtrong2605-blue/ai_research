Machine Learning truyền thống

3. Kiến thức cốt lõi

1. Classification

Phân loại là dự đoán nhãn từ đặc trưng. Iris gồm các phép đo hoa và nhãn loài. Dữ liệu mẫu này dễ học nhưng quá nhỏ để kết luận tổng quát.

2. Baseline là gì?

Baseline là phương án so sánh tối thiểu, như luôn đoán lớp phổ biến nhất hoặc mô hình đơn giản. Nếu không so baseline, khó biết mô hình mới có thực sự cải thiện.

3. Đánh giá công bằng

Chia train/test trước khi học. Không dùng test để chọn thông số liên tục. Dùng random_state để thí nghiệm có thể lặp lại.

4. Không chỉ accuracy

Nếu dữ liệu lệch lớp, accuracy có thể đánh lừa. Confusion matrix, precision, recall, F1 giúp xem các kiểu sai khác nhau.

4. Bài tập và câu hỏi tự kiểm tra

  1. Chạy mã mẫu; ghi accuracy của mỗi mô hình.
  2. Thử đổi random_state: kết quả có đổi không?
  3. Giải thích vì sao một kết quả accuracy cao không có nghĩa “mô hình hoàn hảo”.

5. Ví dụ Python để tự chạy

Mở Google Colab, tạo notebook mới và dán mã dưới đây. Mã tương ứng có trong thư mục examples/.

"""Ngày 4: Baseline vs ML. Cài đặt scikit-learn nếu Colab chưa có."""
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.dummy import DummyClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import accuracy_score, confusion_matrix

X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42, stratify=y
)
models = {
    'Baseline': DummyClassifier(strategy='most_frequent'),
    'Logistic Regression': LogisticRegression(max_iter=1000),
    'Decision Tree': DecisionTreeClassifier(random_state=42),
}
for name, model in models.items():
    model.fit(X_train, y_train)
    predictions = model.predict(X_test)
    print('\n', name, 'accuracy:', round(accuracy_score(y_test, predictions), 3))
    print('Confusion matrix:\n', confusion_matrix(y_test, predictions))
