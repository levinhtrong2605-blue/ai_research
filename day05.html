Deep Learning, NLP và Computer Vision

3. Kiến thức cốt lõi

1. Neuron và tầng

Một neuron tính tổ hợp có trọng số rồi áp dụng hàm kích hoạt. Các lớp liên tiếp học những biến đổi để dự đoán đầu ra.

2. Training và epoch

Mô hình điều chỉnh trọng số dựa trên loss. Epoch là một lượt qua dữ liệu huấn luyện. Nhiều epoch không tự động đảm bảo tốt hơn trên dữ liệu chưa thấy.

3. NLP và Computer Vision

NLP nghiên cứu dữ liệu ngôn ngữ; Vision nghiên cứu ảnh/video. Multimodal kết hợp nhiều loại dữ liệu như văn bản và hình ảnh.

4. Phạm vi thực tế của ngày 5

Ví dụ dùng MLPClassifier từ scikit-learn để thấy mô hình neural nhỏ, không yêu cầu GPU. Bạn sẽ chưa tự cài backpropagation và chưa huấn luyện LLM.

4. Bài tập và câu hỏi tự kiểm tra

  1. Thử hidden_layer_sizes=(32,) và (64,); ghi accuracy.
  2. Thay max_iter và xem cảnh báo hội tụ (nếu có).
  3. Chọn: xử lý văn bản, ảnh hay thuật toán hiệu quả; giải thích bạn muốn giải quyết bài toán gì.
Xem gợi ý định hướng

Mạng nhiều neuron hơn có thể tốn thời gian hơn và không phải lúc nào accuracy test cũng cao hơn.

5. Ví dụ Python để tự chạy

Mở Google Colab, tạo notebook mới và dán mã dưới đây. Mã tương ứng có trong thư mục examples/.

"""Ngày 5: MLP đơn giản trên chữ số viết tay; không cần GPU."""
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
from sklearn.neural_network import MLPClassifier
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline
from sklearn.metrics import accuracy_score

X, y = load_digits(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42, stratify=y
)
for units in (32, 64):
    model = make_pipeline(
        StandardScaler(),
        MLPClassifier(hidden_layer_sizes=(units,), max_iter=500, random_state=42)
    )
    model.fit(X_train, y_train)
    result = accuracy_score(y_test, model.predict(X_test))
    print(f'Hidden units: {units}; test accuracy: {result:.3f}')
